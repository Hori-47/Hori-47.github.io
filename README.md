# 邓旻个人主页

一个面向 GitHub Pages 的单页个人主页，记录具身智能、机器人操作、VLA、强化学习与真机部署工作。

## 发布前需要补充

- `index.html` 中的身份、学校 / 实验室、所在地和公开邮箱
- `assets/images/` 中的叠毛巾和叠杯子演示素材
- CV、数据集索引、模型 checkpoint 和实验日志链接
- 项目中的具体指标、论文或开源仓库地址

页面刻意不复制本地数据集与 checkpoint（这些文件体积较大且可能包含内部信息），只展示经过整理的任务摘要和验证状态。

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。也可以直接将仓库推送到 `main` 分支，通过 GitHub Pages 部署。
